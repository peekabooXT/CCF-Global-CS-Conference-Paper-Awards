# 使用指南

## 查找论文

在[在线数据库](http://47.107.172.42/)的“论文检索”页面，可按会议、CCF 等级、研究领域、年份、奖项、题名、作者和单位等条件筛选。不同筛选条件同时生效，年份范围包含起止年份。

题名、作者和单位支持包含匹配。姓名缩写、中文译名和机构别名可能与来源中的写法不同；没有找到结果时，可以减少筛选条件，或改用论文题名和作者原文。

作者单位与发表时间并非每条记录都已补齐。指定这些条件后，缺少对应信息的记录可能不会出现在结果中。

## 批量筛查论文

“论文总览”位于“论文检索”和“会议年度颁奖”之间，以紧凑表格展示会议、获奖年份、论文题名、作者与已知单位、统一分类、奖项原名、核验状态和来源链接。

会议可多选、全选；年份范围、CCF 等级和奖项分类可组合筛选。快速筛查不区分大小写，多个空格分隔的关键词需要同时匹配，检索范围包括题名、作者、已知单位、会议和奖项原名。筛选即时生效，无需再点检索。

默认按会议 A–Z、年份倒序排列，也可切换年份倒序或题名排序。每页可显示 50、100、200 或 500 条，分页不限制可检索的总量。“展开长文本”显示被折叠的题名、作者和奖项原名。点击题名会在新标签页跳转 Google Scholar；点击“详情”查看本站完整记录与来源。

“导出筛选结果 CSV”导出全部匹配论文，不限当前页。检索、总览、表格、分页和 CSV 均按一篇论文一条统计；同一论文的多个奖项和不同来源名称合并显示，并保留其证据。不同会议或年份的同名论文分别保留。公开版仅展示已核验数据，本地管理版还可筛查核验状态。这个数量代表本系统实际收录论文，不代表该会议官方完整获奖总量。

### 本地重复数据排查

本地管理版上方的“重复数据排查”可扫描同一会议、年份与规范化题名的重复论文实体，以及同一奖项的重复采集记录。系统只统一字母大小写、空白、全角字符及直／弯引号，不自动删除相似题名论文。

展开重复组可对比 ID、作者、论文链接、奖项、来源和核验状态，指定保留哪条、移除哪些。“合并”迁移全部获奖和来源关联，只移除多余实体；“删除选中数据”会删除选中实体及其关联，必须明确确认。不同核验状态不能直接合并，避免将未审核数据自动变为已核验。每次处理都先保存完整 SQLite 备份，并记录处理人和操作；备份位于数据库旁的 `backups` 目录。本地修改不会立即影响服务器，需要再审核发布。

发布窗口会显示重复实体数量。可先人工选择保留项，也可勾选“发布前一键合并已核验重复实体”；系统在发布事务中备份、合并，再构建公开快照。重复检查与删除接口只在本机管理版提供，公开服务器不包含这些功能。

## 本地采集的长文本处理

提取不设置 100000 字符硬上限，不会因为来源正文超过这个长度而阻断。长的多年度获奖页仍会优先提取目标年度段落；没有对应年份标题或段落仍很长时，保留文本继续提取，不按字符数截断。实际请求仍受所选模型及 API 服务的上下文容量、超时和额度约束，长文本可能增加 Token 费用。

## 查看论文详情

展开检索结果，可以查看奖项原名、作者信息、发表时间及来源。官方获奖页用于核对授奖事实；聚合网站的收录信息提供另一条查找线索。来源信息以各条记录实际保存的内容为准。

同一论文可能获得多个奖项。它们属于不同的获奖关联，不应仅因论文题名相同而删除。

## 按会议和年度浏览

“会议年度颁奖”页面将数据按会议、年度和奖项组织，适合查看某个会议当年的获奖论文。没有记录的年度不一定意味着未设奖，也可能尚未收录。

GitHub 上另有[全部论文](../AWARDS.md)、[领域索引](awards/BY_CATEGORY.md)、[年份索引](awards/BY_YEAR.md)和[奖项索引](awards/BY_AWARD.md)，适合直接浏览和分享链接。

## 论文访问与版权边界

本站仅展示论文书目信息、获奖事实和来源索引，不托管、镜像、代理下载或提供论文附件下载。上传用于本地采集的 PDF 等文件不会打包进入服务器公开版。

论文总览的题名直接跳转 Google Scholar：优先沿用已核验收录来源保存的检索地址（保留原题名与作者条件），没有现成地址时按完整题名生成检索。检索链接不是官方授奖证据，也不保证存在免费全文。

有已记录的公开外部论文地址时，另外显示“外部论文 / 出版页面”链接。外部网站提供的下载或访问需遵守其许可与版权要求；Google Scholar 和出版方网站的可访问性由各自服务决定。

## 导出与引用

检索结果支持导出为 CSV，便于整理阅读清单。引用具体获奖事实时，优先引用记录中的官方获奖公告；引用论文时，使用论文出版页面提供的书目信息。

数据更新时间见网站与各索引顶部。论文与官网内容的版权归原作者和发布方所有。
